## F01 应用骨架与登录（已完成）

**交付**

- Vue 3 + TS + Vite + Element Plus 工程，路径别名 `@`。
- 深色侧边栏、顶栏、内容区布局；按 `menu:*` 过滤菜单。
- 登录页（表单校验、记住用户名、演示账号填充、错误提示、redirect）。
- Auth store、token 持久化、`/auth/me` 会话恢复、401 回登录。
- 路由守卫：登录态 + 菜单权限 + 动作权限；403/404。
- 个人中心：用户信息、角色、权限统计、修改密码后强制重新登录。
- MSW 3：登录、me、登出、修改密码；三个演示账号。

**验证**

- `npm run build` 通过。
- `npm run e2e:smoke` 6 项通过：错误密码拒绝、登录、403、登出、管理员访问、登录页渲染。
- 截图：`frontend/artifacts/00-login.png`、`01-chat.png`、`02-forbidden.png`、`03-org-users.png`。

## F02 AI 对话（已完成）

**交付**

- 会话列表（新建、切换、删除）、消息历史加载。
- SSE 流式：`meta → delta* → usage → done`，支持停止生成与错误态。
- Markdown 渲染（markdown-it + DOMPurify）、引用卡片、未授权数量提示。
- FAQ 命中标识、Token 用量、复制/重新生成/反馈。
- MSW：4 个种子会话、按关键词返回不同答案、模拟流式分片。
- 空状态与推荐问题。

**验证**

- `npm run build` 通过。
- `npm run e2e:chat` 6 项通过：种子会话引用、权限提示、流式回答、FAQ 标记、推荐问题、新会话入列表。
- 截图：`frontend/artifacts/04-chat-answer.png`、`05-chat-new-session.png`。
