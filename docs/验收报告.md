## 3. 安全验证

- **未授权内容不泄露**：`test_unauthorized_content_not_leaked` 断言回答与引用不含未授权单元标题、正文关键词；FAQ ACL 测试同样验证。
- **鉴权边界**：普通用户访问知识列表 403；知识管理员写用户 403；无 `ai:access` 用户问答 403。
- **令牌安全**：refresh 轮换、旧 refresh 重放 401、登出吊销、改密后旧 access 失效、禁用账号无法登录。
- **默认拒绝**：未配置任何 `unit_permissions` 的单元对非管理员不可见。
- **管理员不绕过 AI ACL**：问答始终调用权限引擎，管理角色不额外放行。

## 4. 未完成与差异

| 项 | 当前实现 | 目标/后续 |
|---|---|---|
| 向量库 | 数据库 `unit_chunks.embedding_json` + 本地哈希 embedding | 接入 Milvus 2.5（dense + BM25），保留当前实现作为降级 |
| 导入任务 | FastAPI 请求内同步处理 | Celery + Redis，异步任务与断点续跑 |
| FAQ 缓存 | 数据库状态 + 相似度匹配 | Redis 精确缓存 + `faq_vectors` 语义缓存 |
| 会话消息 | PostgreSQL `chat_messages` | MongoDB `chat_messages` |
| 文件与附件 | 原始文件不入对象存储；详情附件 Tab 为空 | MinIO 私有桶 + 预签名 URL + 附件上传 |
| 扫描 PDF | PyMuPDF 文本提取，扫描件失败提示 | MinerU/OCR（默认关闭，显式开启） |
| FAQ 多单元 ACL | 单个 `related_unit_id` | `faq_units` 多对多 + ACL 交集 |
| 按钮级权限 | 路由级 `menu:*` + 动作权限 | 前端按钮 `v-permission` 全面接入 |
| 看板日聚合 | 实时查询日志 | `dashboard_daily_stats` + Celery beat |
| 测试环境 | SQLite 默认、PostgreSQL 可切换 | Compose 集成测试与性能基线 |
