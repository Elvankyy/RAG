# 接口说明

Base URL：`http://127.0.0.1:8000`（或实际部署地址）。除登录/健康检查外，均需 `Authorization: Bearer <access_token>`。

## 1. 认证

| 方法 | 路径 | 权限 | 请求 | 响应 |
|---|---|---|---|---|
| POST | `/api/auth/login` | 公开 | `username`、`password` | `access_token`、`refresh_token`、`token_type`、`user_info`、`permissions` |
| POST | `/api/auth/refresh` | 公开 | `refresh_token` | 同上；旧 refresh 立即失效 |
| POST | `/api/auth/logout` | 登录态 | `refresh_token?` | `message` |
| GET | `/api/auth/me` | 登录态 | — | 用户、部门、角色、权限 |
| PUT | `/api/auth/password` | 登录态 | `old_password`、`new_password` | `message`；旧 access 与全部 refresh 失效 |

## 2. 组织架构

| 方法 | 路径 | 权限码 |
|---|---|---|
| GET | `/api/org/departments` | `dept:read` |
| POST/PUT/DELETE | `/api/org/departments[/{id}]` | `dept:create/update/delete` |
| GET | `/api/org/users?keyword=&department_id=&status=` | `user:read` |
| POST/PUT/DELETE | `/api/org/users[/{id}]` | `user:create/update/delete` |
| POST | `/api/org/users/{id}/reset-password` | `user:reset` |
| POST | `/api/org/users/{id}/status` | `user:update` |
| GET | `/api/org/roles` | `role:read` |
| POST/PUT/DELETE | `/api/org/roles[/{id}]` | `role:create/update/delete` |
| POST | `/api/org/roles/{id}/permissions` | `role:assign` |
| GET | `/api/org/permissions` | `role:read` |

用户对象字段：`id`、`username`、`display_name`、`department_id`、`department_name`、`status`、`role_ids`、`role_names`、`created_at`。

## 3. 知识维护

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/knowledge/categories` | `knowledge:read` | 分类与数量 |
| GET | `/api/knowledge/units` | `knowledge:read` | `keyword`、`category`、`status`、`page`、`page_size`；非管理员按 ACL 过滤 |
| POST | `/api/knowledge/units` | `knowledge:create` | 标题、正文、分类、标签、权限 |
| GET/PUT | `/api/knowledge/units/{id}` | `knowledge:read/update` | 更新递增版本并重建切片 |
| DELETE | `/api/knowledge/units` | `knowledge:delete` | body `{ids:[]}` |
| GET/POST | `/api/knowledge/units/{id}/permissions` | `knowledge:read/permission` | 四维权限 |
| GET | `/api/knowledge/units/{id}/versions` | `knowledge:read` | 版本列表 |
| POST | `/api/knowledge/units/{id}/versions/{v}/rollback` | `knowledge:update` | 回滚 |
| POST | `/api/knowledge/units/{id}/reindex` | `knowledge:update` | 重建切片与向量 |
| POST | `/api/knowledge/import` | `knowledge:import` | multipart：`files[]`、`category`、`tags` |
| GET | `/api/knowledge/import/batches/{id}` | `knowledge:import` | 批次与任务 |
| POST | `/api/knowledge/import/tasks/{id}/retry` | `knowledge:import` | 失败重试 |
| POST | `/api/knowledge/check-permissions` | 登录态 | `user_id?`、`unit_ids[]` → `authorized_unit_ids`、`unauthorized_unit_ids` |

知识单元字段：`unit_code`、`title`、`summary`、`category`、`file_type`、`file_size`、`status`、`creator_name`、`version`、`chunk_count`、`index_status`、`permissions[]`、`permission_summary`、`created_at`、`updated_at`；详情额外返回 `content`。

## 4. AI 问答

| 方法 | 路径 | 权限码 |
|---|---|---|
| POST | `/api/ai/chat/stream` | `ai:access` |
| GET | `/api/ai/sessions` | 登录态 |
| GET | `/api/ai/sessions/{id}/messages` | 登录态（仅本人） |
| DELETE | `/api/ai/sessions/{id}` | 登录态（仅本人） |

SSE 事件：

| event | 关键字段 |
|---|---|
| `meta` | `session_id`、`faq_hit`、`citations[]`、`unauthorized_count`、`recalled_count`、`authorized_count` |
| `delta` | `content` |
| `usage` | `prompt_tokens`、`completion_tokens`、`total_tokens`、`token_source` |
| `done` | `log_id`、`session_id`、`response_time_ms`、`first_token_ms`、`total_tokens`、`citations[]`、`unauthorized_count`、`faq_hit`、`permission_notice` |
| `error` | `message` |

`citations[]`：`index`、`unit_id`、`unit_code`、`title`、`category`、`score`、`snippet`。未授权内容不出现在任何事件中，只返回数量。

## 7. 错误与状态码

| 状态码 | 含义 |
|---|---|
| 400 | 参数或状态非法（重复用户名、删除受限、密码过弱等） |
| 401 | 未登录、令牌过期、refresh 失效、旧 access 失效 |
| 403 | 操作权限不足、数据权限不足、账号禁用 |
| 404 | 资源不存在 |
| 409/422 | 冲突 / 请求校验失败（FastAPI 默认） |

错误体：`{"detail": "..."}`；SSE 业务错误通过 `event: error` 返回。
