# 采购审批流程

## 适用范围
本流程适用于办公用品、设备、软件服务与外包服务的采购。

## 审批权限
1. 单笔金额 5000 元以下：部门负责人审批；
2. 单笔金额 5000 元至 20000 元：部门负责人 + 财务负责人审批；
3. 单笔金额超过 20000 元：部门负责人 + 财务负责人 + 总经理审批。

## 采购流程
需求提出 → 部门负责人审批 → 采购询价（至少 3 家）→ 财务审核预算 → 签订合同 → 验收入库 → 付款。
采购完成后需在资产系统登记，软件服务需同步登记到期时间。

## 紧急采购
因生产故障等紧急情况可先采购后补流程，但需在 3 个工作日内补齐审批材料。
